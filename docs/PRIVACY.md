# Privacy policy

Last updated: 2026-10-11

TubePreview is an independent Android tool for previewing thumbnails and titles. It does not connect to a YouTube account.

## Local data

The app stores your channel name, imported channel photo, thumbnail options, titles, crop positions, and preview preferences in private storage on your device. These images and settings are not uploaded to a server.

The app has no analytics SDK, advertising SDK, account system, or backend. Selecting an image uses Android's system picker; the app copies only the selected file into its private storage.

## Network requests

Sample feed and avatar photos are loaded from Unsplash over HTTPS. Unsplash receives ordinary request information, including your IP address and the requested image URL. Its processing is governed by [Unsplash's privacy policy](https://unsplash.com/privacy).

The app requests Android's Internet permission to load these images. It does not request camera, microphone, location, or broad media-library access.

## Deleting data

Resetting previews in Settings removes imported images and restores preview defaults while preserving completion of first-run setup. Clearing app data or uninstalling removes all local app data. App data is excluded from Android cloud backup and device transfer.

## Contact

For privacy questions, [open an issue](https://github.com/notrenflare/TubePreview/issues) without including private images or personal information. Report security concerns privately using [the security policy](../SECURITY.md).
