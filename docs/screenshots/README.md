# App screenshots

These screenshots show TubePreview running on a Samsung Galaxy A55. They use the
app's sample content and the `renflare` channel name.

To refresh an image, open the corresponding screen on a connected Android device
and capture it with the Android CLI:

```sh
android screen capture --output=docs/screenshots/home-dark.png
```

Review screenshots for private content before committing them. Keep filenames
consistent so the root README continues to display them.
